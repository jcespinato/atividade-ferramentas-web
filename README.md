## Como publicar no GitHub Pages
1. Crie um repositório no GitHub, por exemplo: `atividade-ferramentas-web`.
2. Coloque todos os arquivos deste projeto na raiz do repositório.
3. No GitHub, abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch **main** e a pasta **/(root)**.
6. Clique em **Save** e aguarde o endereço público ser gerado.
7. Copie esse endereço e coloque no campo de verificação do tutor na atividade.
